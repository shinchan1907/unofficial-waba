Manage your connected WhatsApp accounts.

API Documentation

All API endpoints require authentication via the x-api-key header or ?api_key= query parameter.

POST /api/accounts

Create a new WhatsApp account session.

Body (JSON)

{
  "name": "marketing"
}
GET /api/accounts

List all WhatsApp accounts and their connection status.

GET /api/accounts/:id/qr

Get the QR code for a specific account. Returns base64 image data or raw image.

GET /api/accounts/:id/status

Get connection status of a specific account.

Response

{
  "status": "CONNECTED",
  "number": "919999999999"
}
POST /api/messages/send

Send a text or media message from a specific account. Messages are automatically queued.

Body (JSON) - Text Message

{
  "account": "marketing",
  "number": "919999999999",
  "message": "Hello customer"
}

Body (JSON) - Media Message

{
  "account": "marketing",
  "number": "919999999999",
  "message": "Caption goes here",
  "media": {
    "type": "image", 
    "url": "https://example.com/photo.jpg"
  }
}

* `type` can be `image`, `video`, or `document`.

POST /api/accounts/:id/logout

Logout and completely delete a session for a specific account.

PUT /api/accounts/:id/webhook

Configure a custom webhook URL for a specific account to receive incoming messages.

Body (JSON)

{
  "webhookUrl": "https://hook.eu1.make.com/your-id"
}

Incoming Webhook Format

If a webhook is configured, the server will POST incoming messages in this format:

{
  "account": "marketing_bot",
  "sender": "919876543210",
  "text": "Hello, I need help with my order!",
  "messageType": "conversation",
  "timestamp": "2024-06-12T10:30:00.000Z"
}
