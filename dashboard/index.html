API Documentation

All API endpoints require authentication via the x-api-key header or ?api_key= query parameter.

POST /api/accounts

Create a new WhatsApp account session.

Body (JSON)

{
  "name": "marketing"
}
GET /api/accounts

List all WhatsApp accounts and their connection status.

GET /api/accounts/:id/qr

Get the QR code for a specific account. Returns base64 image data or raw image.

GET /api/accounts/:id/status

Get connection status of a specific account.

Response

{
  "status": "CONNECTED",
  "number": "919999999999"
}
POST /api/messages/send

Send a text message from a specific account. Messages are automatically queued.

Body (JSON)

{
  "account": "marketing",
  "number": "919999999999",
  "message": "Hello customer"
}
POST /api/accounts/:id/logout

Logout and delete session for a specific account.
